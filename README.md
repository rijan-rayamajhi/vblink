# vblink

Offline social-casino game built with Flutter (landscape, iOS + Android).
Play coins only — no real money, no network.

## Run

```sh
flutter pub get
flutter run
```

## Layout

- `lib/features/lobby/` — lobby screen (top bar, game panel, reward bar)
- `lib/economy/` — wallet, jackpots, task reward timer
- `assets/images/` — game art
